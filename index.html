emailrecon

Check whether an email address is registered across 116 public websites — in parallel, in your browser.

Two ways to run. Backend mode is the reliable one: start server.py, put its URL above (e.g. http://127.0.0.1:8777), and the checks run server-side — no CORS, and cookies work normally, so the cookie-based checks (LastPass, Eventbrite, Strava, Zoho…) work too. Live mode calls the sites straight from the page, which browsers block without a CORS proxy. Demo simulates results for exploring the UI. Every hit is graded by confidence and links to the site so you can verify it. Use only on addresses you own or are authorised to check.

A hit means an account may exist — verify before relying on it. No logins, no password attempts, no private data: every check calls the same public "is this email available?" endpoint the site's own sign-up or reset form uses.
